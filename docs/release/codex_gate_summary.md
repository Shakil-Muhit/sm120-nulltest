# Codex review gates — two-paragraph summary (Phase 3 §2.8)

Eight gates were run with OpenAI Codex (model gpt-6-astra, reasoning effort max, read-only sandbox) as an adversarial partner between 2026-09-19 and 2026-09-20, each against a named commit, with the prompt, the verdict and the full transcript kept in `docs/codex/` (`prompt_NN_*.md`, `NN_*.md`, `NN_*.log`). Gate 01 reviewed the design (5 blockers), gate 02 the first code drop (10 blockers), and gates 03–08 verified successive commits of the harness against the registration and the plan using code inspection, CPU counterexamples and in-memory tests. Findings are numbered continuously: 1–32 across the design and code gates, 33–45 (gate 03), 46–60 (gate 04, commit 602a52a), 61–77 (gate 05, b039272), 78–96 (gate 06, 43c9e29), 97–111 (gate 07, 845ba99, verdict "EXECUTION-READY: no") and 112–127 (gate 08, e523ef9). The findings that changed the measurement path were fixed before session 1: among them, the matched-pair eligibility initialisation, the perturbation traces deleting reductions, the qualification and completeness identity checks (findings 112–116), and the case-insensitive nsys column handling discovered on the pod and fixed post-session with the correction recorded (commit c6fd1c3; `docs/EXECUTION_REPORT_2026-09-20.md`).

Gate 08's remaining findings (114–127) concern audit strictness rather than numbers: whether invalid records could receive HEADLINE and COMPLETE labels, whether completeness compares every manifest field, and similar validator hardening. The owner ruled on 2026-09-20 that these do not corrupt any reported number and deferred them ("do not nitpick for small issues"); they stay listed in gate 08 as open. Under the Phase-3 rule R7, two further gates are planned: one on the E1–E9 experiment specifications and their measurement path before the pod, and one on the analysis tools after the session. The gates' reliability caveat, for the paper: an agent reviewer's verdict is evidence of what was checked, not of correctness; the transcripts show what was examined and what was not, and the deferred findings are disclosed rather than silently closed.
